# OneSearch

管理多个 Meilisearch 实例的控制台。前端使用 React、Mantine 和 TanStack Query，界面参考并迁移 Moment 的主题、分段切换、账户布局和表单样式；后端使用 Go、SQLite。

当前为本地 dev 版本。实例运行在真实的本地 Meilisearch 进程中，无需启动 Docker。最终服务器版本采用 Docker，相关运行时尚未实现。

## 开始使用

打开 [本地控制台](http://localhost:5178/)。Go API 在 `127.0.0.1:7800`，托管实例自动分配 `7810–7899` 端口。

首次登录信息在 `data/dev-login.txt`。修改密码后该文件删除，后续使用新密码。不要把 `data/` 上传至 Git 或公开服务器。

启动步骤见 [开发说明](docs/dev.md)。

## 当前能力

- 创建真实本地实例、接入已有本机实例；启动、停止、重启、归档。
- 多索引管理、文档 JSON/NDJSON 导入、实际搜索、搜索设置、异步任务和运行日志。
- 按索引生成搜索或发布密钥，创建时显示密钥值，列表隐藏已有密钥值。
- 公开搜索入口：站点来源白名单、CORS、索引密钥、IP 限流和结果数限制。
- 实例树与索引快捷访问，实例内操作记录；实例统计和年度搜索活动热力图。
- 搜索请求历史：实际连接 IP、来源、设备、状态、耗时、结果数和部分搜索参数；保留 30 天。
- 文档与搜索：分页、每页数量、高亮摘要、命中位置及完整 JSON 响应。
- 账户设置：通行密钥、TOTP、一次性恢复码、修改密码、登录会话和中文审计日志。
- 加密的平台配置备份和托管实例 dump 备份、下载、离线解密工具。
