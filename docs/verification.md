# 当前验证记录

日期：2026-10-03。记录实际检查结果，不代表已经完成生产验收。

## Go 安全与协议边界测试

`go test ./...` 已通过。

- 密码登录在启用 TOTP 后拒绝缺少第二因素的请求。
- RFC 6238 示例的 6 位截断结果正确；消费过的时间步无法再次使用。
- 恢复码只可使用一次。
- 撤销其它会话后，旧会话访问管理接口返回 401。
- 修改密码拒绝错误旧密码，旧密码与旧会话失效，当前会话轮换后可用，新密码可登录。
- WebAuthn 挑战绑定会话并单次消费；合成认证器完成注册和实际 ECDSA 签名登录；错误 Origin、篡改签名、异常计数器被拒绝。
- 公开搜索拒绝不允许的 Origin、拒绝主密钥，执行结果上限和 IP 限流；limit/hitsPerPage 均受上限约束，格式和分页元数据完整透传。
- 过期会话可直接注册通行密钥（仍通过完整 WebAuthn 验证），未登录无法注册；未配置 TOTP 时身份验证只要求密码。
- 不信任客户端伪造的 X-Forwarded-For，失败请求也记录历史。
- 每日聚合按实例隔离，原始历史清理后依然保留；实例操作只返回目标实例记录。
- 管理请求缺少校验标识被拒绝；任意引擎路径和穿越路径未开放。
- 加密备份可解密，错误密码和篡改失败；平台副本不含会话；ZIP 穿越路径拒绝。
